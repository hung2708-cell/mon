🚀 Hướng Dẫn Đưa Web Lên GitHub Pages (Miễn Phí)

📌 Bước 1: Lưu mã nguồn

Lưu toàn bộ mã nguồn của trang web này thành một tệp có tên chính xác là: index.html

📌 Bước 2: Tạo Repository trên GitHub

  1. Truy cập github.com và đăng nhập tài khoản.
  2. Bấm nút New (hoặc dấu + ở góc trên bên phải) để tạo Kho lưu trữ (Repository) mới.
  3. Đặt tên gợi nhớ (ví dụ: hoc-vui-lop-2), chọn Public rồi bấm Create repository.

📌 Bước 3: Tải tệp lên GitHub

  1. Tại trang Repository vừa tạo, chọn link "uploading an existing file".
  2. Kéo thả tệp index.html vào trang web.
  3. Bấm nút màu xanh Commit changes ở phía dưới.

📌 Bước 4: Kích hoạt GitHub Pages

  1. Vào tab Settings của Repository đó.
  2. Tìm mục Pages ở danh sách menu bên trái.
  3. Tại phần Build and deployment -> Branch, chọn nhánh main (hoặc master) và thư mục /(root).
  4. Bấm Save.

🎉 Bước 5: Hoàn tất & Chia sẻ!

Đợi khoảng 1 - 2 phút, GitHub sẽ cấp cho bạn một đường link dạng:
https://ten-tai-khoan.github.io/hoc-vui-lop-2/
Bây giờ bé có thể truy cập đường dẫn này trên điện thoại, máy tính bảng hoặc máy tính để học rồi!
